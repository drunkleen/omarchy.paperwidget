# Omarchy Paper Widget

An Omarchy shell plugin that displays a Stencil Pixel-7 clock and day/date at the bottom-left of the desktop.

## Install

Install it through Omarchy's plugin manager or clone it into the local plugin directory:

```bash
omarchy plugin add git@github.com:drunkleen/omarchy.paperwidget.git --enable
```

This plugin is intended for Omarchy's Quickshell environment.
